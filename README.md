# אותו סיכום, צורה אחרת

ארבע סדרות, 11 נקודות בכל אחת (Anscombe, 1973).
הממוצע, השונות והמתאם יוצאים כמעט זהים. השרטוט לא.

```
set   n   mean_x  mean_y   var_x   var_y   corr
I    11    9.000   7.501  11.000   4.127   0.816
II   11    9.000   7.501  11.000   4.128   0.816
III  11    9.000   7.500  11.000   4.123   0.816
IV   11    9.000   7.501  11.000   4.123   0.817
```

I כמעט קו ישר עם רעש. II מתעקלת. III ישר, עם נקודה אחת רחוקה. IV כמעט כל ה-x על 8, ונקודה אחת על 19.

השארית הגדולה ביותר מהקו הישר (ריבועים פחותים), והנקודה עצמה:

```
set   max_abs_residual   point
I       1.921   13.000,7.580
II      1.901   4.000,3.100
III     3.241   13.000,12.740
IV      1.839   8.000,8.840
```

III רחוקה יותר מ-I. ב-IV כמעט כל ה-x על 8, והנקודה על 19 יושבת על הקו. השארית הגדולה היא דווקא אחת מנקודות ה-8. R² הוא ריבוע המתאם, בערך 0.666 בכל ארבע הסדרות. `anscombe.svg` מצייר את ארבע הצורות על אותם צירים, וטבעת מסמנת את הנקודה הרחוקה בכל לוח.
